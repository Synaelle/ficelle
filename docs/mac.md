# Ficelle on a Mac

I recommend the [web version](https://ficelle.synaelle.com/web/). I no longer make the Mac app, having no Mac to test it.

The last Mac app, [0.7.1](https://github.com/Synaelle/ficelle/releases/download/v0.7.1/Ficelle_0.7.1_universal.dmg), was never tried on a real Mac and gets no updates. If macOS refuses it, click Open Anyway in System Settings, Privacy & Security, or run this once in Terminal.

```sh
xattr -dr com.apple.quarantine /Applications/Ficelle.app
```
