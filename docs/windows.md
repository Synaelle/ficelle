# Windows warning

When you open Ficelle on Windows for the first time, SmartScreen may show "Windows protected your PC" and name an unknown publisher. Choose More info, then Run anyway.

Windows shows this for any program that is not signed with a code signing certificate. Such a certificate costs a few hundred euros a year and has to be renewed, which is too much for a free app I make alone in my spare time. The warning says nothing about the program itself, only that Windows does not know who made it.

Every release on GitHub is built from the public source code by GitHub's own machines. GitHub shows the SHA-256 checksum of each file on the release page, so you can compare it with the file you downloaded.
