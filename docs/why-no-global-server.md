# Why there is no global sync server

I don't host a sync server for everyone, and I don't plan to. Keeping other people's notes on a server I run would make me legally responsible for them. Under European law that means answering requests to see or delete data, reporting breaches within days, replying to requests from authorities, and dealing with complaints about what people store, even when the notes are encrypted and I can't read them. That is a job for a company with lawyers, not for one person making a notes app in their spare time.

Your notes stay on your devices, which sync directly with each other on the same network, or on a sync server you run yourself.
